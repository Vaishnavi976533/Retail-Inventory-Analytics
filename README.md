# Retail Inventory Analytics Using Google Colab

## Project Overview

This project analyzes retail inventory data using Python and Google Colab. The analysis helps identify top-selling categories, low-stock products, supplier contributions, and inventory trends.

## Objectives

* Analyze category-wise sales performance
* Identify products approaching reorder levels
* Evaluate supplier contribution
* Study inventory trends
* Generate business insights

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
* GitHub

## Analysis Performed

* Data Understanding
* Data Cleaning

* Business Insights Generation
